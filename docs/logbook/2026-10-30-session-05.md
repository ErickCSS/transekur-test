## Problems found
- **shadcn CLI and the `utils` alias**: with a non-`lib/utils` path the CLI imported `cn` from a package called `cn` and installed it from npm. Fix: removed the package, pointed the imports at `shared-class-names.utils`, and installed `class-variance-authority`, `clsx`, `tailwind-merge`, `lucide-react` and `tw-animate-css` by hand.
- **`--accent` means two things**: amber in this app, a grey hover color in shadcn. Kept amber and changed the generated hovers.
- **Optimistic row with its own id**: with `AnimatePresence`, the board would have animated the row out and the saved one in. Fixed by sharing the id.
- **Blank selects on first paint**: Radix fills `SelectValue` only after hydration. Fix: pass the selected text as its children, so it is in the server HTML.
- **No empty option in Radix Select**: "no driver" uses the value `unassigned`, mapped back to an empty driver in `dispatch-driver-select.config.ts`.
- **The CLI again**: `shadcn add calendar` reinstalled `cn` and stopped at a prompt to overwrite our `button.tsx`; the calendar was written by hand from the shadcn source (react-day-picker 10), already in the brand colors.
