## Problems found
- **"The list reset" after creating a service**: the new service was for tomorrow, and the board jumped to that day, where only that service existed, so the demo list looked gone. The driver app didn't show it because it only listed today's services. Fix: stay on the current day, add the row optimistically, say clearly which day it's for, and show tomorrow's services in the driver app.
- **Live pill stuck on "Connecting…"**: `supabase.channel(name)` returns the existing channel while the previous one is still unsubscribing (React mounts effects twice in dev, and moving between screens does the same). Fix: one channel per tab, opened once, with listeners added and removed.
