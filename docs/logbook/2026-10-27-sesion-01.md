# Sesión 01 — 2026-10-27

## Objetivo
Entender la prueba, decidir la arquitectura y tener el diseño de las pantallas listo para validar.

## Decisiones
- Una app con home de 3 opciones ([0001](../decisions/0001-una-app-tres-modulos.md)).
- Supabase como backend ([0002](../decisions/0002-supabase.md)).
- Aviso simulado + link WhatsApp ([0003](../decisions/0003-aviso-simulado-whatsapp.md)).
- Login real con Supabase Auth ([0004](../decisions/0004-login-conductor-supabase-auth.md)).
- Convenciones modulares; la entidad *service* se llama `Trip` en código ([0005](../decisions/0005-convenciones-modulares.md)).
- Diseño primero con base mock ([0006](../decisions/0006-diseno-primero-con-mock.md)).
- UI en inglés, docs en español.

## Hecho
- Instalados `@supabase/supabase-js`, `@supabase/ssr` y `server-only`.
- Carpeta `docs/` con índice, ADRs, arquitectura, diseño y esta bitácora.
- Módulos: `shared`, `home`, `dispatch`, `driver-auth`, `driver`, `client-notice`, `notifications`.
- Login real con Supabase Auth; 3 cuentas de prueba creadas con `scripts/seed-driver-accounts.mjs`.
- `proxy.ts` protege `/driver/services` y manda a un conductor ya logueado fuera del login.
- Base mock en `localStorage` compartida entre pestañas (ADR 0006).
- Pantallas Home, Dispatch, Driver (login + servicios del día) y Client (bandeja + WhatsApp).

## Problemas encontrados
- **`Date.now()` durante prerender**: con `cacheComponents`, el cliente de Supabase lee el reloj al cargar la sesión. Solución: `await connection()` en `createSupabaseServerClient` para forzar request time.
- **Fechas en client components**: para no usar `new Date()` en el render del servidor, el contenido que depende de la base mock solo se monta en el cliente (`SharedMockDatabaseGate`).

## Verificado
- `pnpm lint`, `tsc` y `pnpm build` sin errores.
- Flujo en el navegador: crear servicio en dispatch → login de Carlos (móvil) ve solo sus 3 servicios de hoy → "I'm 10 min away" → el cliente ve el mensaje con nombre y vehículo + link `wa.me` correcto → dispatch muestra *Sent 07:53 PM*.
- Sign out redirige a `/driver` y `/driver/services` queda protegido.
